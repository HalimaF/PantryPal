Status: approved · spec.md is the canonical copy · Implements prd.md.

How It Fits Together

Three Google services and no server of our own. Firestore is a spreadsheet in the cloud, one set of sheets per person.

Gemini service — four requests, each returns JSON
  • identifyItem(photo) → item name
  • suggestDishes(preferences, stock, profile, recentMeals) → dishes
  • getRecipe(dish) → ingredients + steps
  • estimateUsed(dish, photo?) → amounts used
Days until shopping (your definition)

Days = next shopping date − today. Shopping on the 28th means the next date defaults to the 28th of next month, and you can change it. Home also lists each item's remaining quantity and a total, so mum judges whether it will last.

Where Data Lives

Firestore layout
users/{uid}                  profile + lastShoppingDate, nextShoppingDate
users/{uid}/inventory/{id}   name, quantity, unit, weightKg, addedAt
users/{uid}/meals/{id}       date, dishName, used[], slot

Rules: a signed-in user can only read and write their own users/{uid}. Everything is still there when she comes back.

Where It Runs

  • Run: flutter pub get then flutter run on an Android phone or emulator.
  • Family install: flutter build apk --release, then share the APK.
  • Demo video: screen-record: sign up → add groceries (photo + text) → suggestion → recipe → log dish → remaining list changes.
  • Submission: short demo video + public GitHub repo. Deployment is optional.

What Could Break

  • Gemini slow or rate-limited → “Thinking…”, then a friendly message with Retry; the text option still works.
  • Bad or invalid AI reply → retry once, then “please type it.” The item name is always editable.
  • No internet → clear message; saves are one document at a time.
  • No dish fits → the empty message from the PRD.

Simplified on Purpose

  • Email/password login only, no social login.
  • Plain widgets and Firestore streams, no state library.
  • Calendar days until shopping plus the remaining list, no prediction of how long food lasts.
  • AI-written recipes on demand, no recipe database.
  • Android only.

Decisions and Open Issues
